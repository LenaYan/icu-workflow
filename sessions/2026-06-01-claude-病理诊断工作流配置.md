# Session: 如何用 Claude 做病理诊断 + 提高准确性的配置
Date: 2026-06-01

## Background / Context

用户（ICU 主治）询问：如何用 Claude 进行病理诊断、应做哪些配置以提高准确性。

讨论核心：**Claude 不能也不应该用于一线病理诊断**。它不是 NMPA/FDA/CE 认证的医疗器械，不是病理 foundation model，不能读 WSI。准确性的关键不在"配置 Claude"本身，而在"把 Claude 放在工作流的哪一格"。错位的工作流再多配置也救不回来。

---

## Key Decisions

1. **不把 Claude 当病理诊断引擎**。定位为：病理报告的临床翻译器 + 鉴别诊断/IHC 的查得手 + 报告结构化工具。
2. **一线诊断、冰冻判读、单图诊断** —— 禁止使用 Claude。
3. 工作流核心提升手段是**输入结构化模板**（五段式），而非"调提示词"。
4. 任何 Claude 输出必须经 WHO Blue Book / UpToDate / PubMed 近 5 年 review **双重验证**。
5. 病理材料 PHI 比病程更敏感（含病案号/姓名/切片号/送检日期），入库前严格去标识化，截图先打码。

---

## Generated Plan / Solution

### 一、能力边界

**技术层**
- Claude 通用多模态，**不是**病理专用模型（对照：Paige PanCancer / PathAI / Lunit SCOPE / 国内透彻影像 ThorouGood / 迪英加 Doraemon-DPMS / 兰丁 LBP）
- 不能读 WSI（.svs/.ndpi/.mrxs 金字塔），只能读手动截取的 PNG/JPG 视野 —— 视野选择本身即 bias source
- 染色差异（H&E vs IHC vs special stain）、扫描仪差异、切片质量均影响识别
- 数字病理 SOTA 是 tile-level CNN/ViT 在数万张 WSI 上预训练 —— Claude 架构与训练集不符

**监管层**
- 国内 AI 辅助病理诊断为 **NMPA 三类医疗器械**（透彻 ThorouGood、迪英加 Doraemon-DPMS、兰丁 LBP 均已取证）
- Claude 无医疗器械注册 → 诊断责任仍在签字病理医生

### 二、ICU 医生实际可用场景（按价值排序）

| 用途 | Claude 适配度 | 说明 |
|---|---|---|
| 读已签发的病理报告 → 指导临床决策 | ✅ 高 | 翻译 + 关联临床 |
| 床旁活检前后的鉴别诊断思路（肺活检 DAD vs OP vs AEP vs HP） | ✅ 高 | 给鉴别清单，不出诊断 |
| 尸检/死亡讨论的组织学 ↔ 临床关联 | ✅ 高 | 多脏器整合 |
| 科研：病理报告字段结构化 + 临床数据关联 | ✅ 高 | 文本结构化强项 |
| IHC panel 合理性校验 | ⚠️ 中 | 需双重验证 |
| 一线诊断（单图 → 诊断） | ❌ 禁 | 不要做 |
| 冰冻切片快速判读 | ❌ 禁 | 不要做 |

### 三、提高"辅助准确性"的配置实操

**(a) 输入结构化五段式**（最关键）

```
临床背景：年龄/性别/主诉/影像/实验室/治疗史
大体所见：部位/取材方式/大小/外观
镜下所见：组织结构/细胞形态/核特征/核分裂/坏死/侵犯
IHC/特殊染色：阳性/阴性 + 强度 + 比例（如 TTF-1+ strong 80%、p40-）
分子检测：突变/融合/MSI/TMB（如有）
```
缺项必须明写"未做/未提供"，**不让 Claude 脑补**。

**(b) 项目级 `CLAUDE.md` 病理子规范要点**
- 强制引用：WHO Classification of Tumours 5th ed（2021–2024 各卷）、AJCC 8th、CAP protocols、NCCN、专科共识（ATS/ERS for ILD、ISN/RPS for renal、Banff for transplant、ISHLT for cardiac transplant）
- 输出格式固定：**鉴别诊断列表 + 关键鉴别点 + 期望 IHC panel + don't-miss 诊断 + 推荐进一步检查**
- 不出"最终诊断"

**(c) 强制双重验证**
- Claude 给鉴别 → 回查 WHO Blue Book / UpToDate / PubMed 近 5 年 review 至少 1 篇
- 高频鉴别点建速查表入库，**每次直接引用而非重新生成**（如 mesothelioma vs adenocarcinoma 的 IHC、TMA vs DIC 的肾病理、DAD vs OP）

**(d) 目录骨架建议**

```
pathology/
├── _templates/
│   ├── ihc-panel-by-organ.md       # 按器官 IHC 速查
│   ├── differential-by-pattern.md  # 按形态模式鉴别
│   └── report-interpretation.md    # 解读报告五段式
├── critical-care/                  # ICU 高频
│   ├── lung-biopsy-ARDS.md         # DAD / OP / AEP / HP / DAH
│   ├── renal-biopsy-AKI.md         # ATN / AIN / TMA / cast nephropathy
│   ├── liver-failure.md            # 急性肝衰组织学
│   ├── transplant-rejection.md     # Banff / ISHLT
│   └── autopsy-protocols.md
└── notes/                          # 单次咨询记录（PHI 去标识化）
```

**(e) PHI 红线**
- 病理报告含病案号/姓名/切片号/送检日期，比病程更敏感
- 按 `cases/README.md` 去标识化规则严格处理
- 截图 IHC/HE 前先打码标签

### 四、明确禁止

- ❌ 拍一张切片图 → 问 Claude "这是什么"
- ❌ 跳过 IHC / 分子检测，让 Claude 直接定型
- ❌ 把 Claude 输出写进病理报告或病程记录
- ❌ 用 Claude 替代会诊（疑难病例转上级病理科 / 会诊平台仍是金标准）
