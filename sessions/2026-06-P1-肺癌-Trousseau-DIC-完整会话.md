## 三、Generated Plan / Solution（全文）

### A. 鉴别诊断框架

**主要矛盾**：活动性出血（鼻 + 咯 + 颅内可能 SAH） ⇄ 未控制的 cancer-associated VTE（双下肢 DVT + IVC 滤网在位） ⇄ PLT 34 + Fib 0.81 + 多通路血小板功能抑制

**最优先鉴别：Trousseau syndrome / 肿瘤相关慢性 DIC**

ISTH overt DIC 评分（暂以现有数据）：
- PLT < 50 → 2 分
- Fib < 1.0 → 1 分
- PT 延长 < 3 s → 0 分
- D-dimer/FDP 待补 → 预计 3 分
→ 估算 ≥ 6 分，符合 overt DIC

**需要同步排除**：
1. 新发颅内出血进展 / SAH（最致命）— 头颅 CT 复查必做
2. 脑转移瘤合并瘤卒中（MRI 已提示）
3. TMA / MAHA（肿瘤 / 化疗相关）— 外周血涂片 schistocytes、LDH、间接 Bil、Coombs
4. 靶向药相关血液毒性（EGFR-TKI、ALK-i、贝伐单抗）— 待明确具体药物
5. HIT（如近期 UFH/LMWH 暴露）— 4Ts + 抗 PF4
6. 骨髓浸润 / 化疗骨抑（优先级低）

### C. 出血支持医嘱（床旁，next 6h，立即执行）

#### C1. 血小板输注
```
单采血小板 1 治疗量 (≥2.5×10¹¹) ivgtt 立即输注，必要时 q12h
└─ 目标 PLT:
   • 无 ICH / 无侵入性操作 → ≥ 50 × 10⁹/L
   • 怀疑/证实 ICH 或 SAH → ≥ 100 × 10⁹/L    [AABB 2015; BSH 2017]
└─ 输前/输后 1h PLT 评估 CCI（< 7.5 警惕 HIT/ITP/脾大）
```

#### C2. 纤维蛋白原（目标：ICH ≥ 2.0；其他大出血 ≥ 1.5 g/L）

**首选 — 人纤维蛋白原浓缩剂**：
```
人纤维蛋白原 4 g ivgtt 立即（首剂）
└─ Δ Fib (g/L) ≈ 给药剂量 (g) / 0.04 / 体重 (kg)
└─ 50 kg 输 4 g → 理论升高 ~ 2 g/L
└─ 30-60 min 后复查；仍 < 1.5 → 追加 2 g
```

**次选 — 冷沉淀**：
```
冷沉淀 10 U ivgtt 立即（1 U/10 kg ≈ Fib +0.5-0.7 g/L）
注意：容量负荷 ~ 200-300 mL，老年慎防
```

#### C3. FFP — 不优先
```
仅当 PT/APTT > 1.5× ULN + 出血：10-15 mL/kg（50 kg → 500-750 mL）
```

#### C4. 红细胞触发
```
一般 ICU：Hb < 70                              [TRICC]
ACS / 严重缺血 / SAH 痉挛期：< 80-90
```

#### C5. 抗纤溶 — 本患者明确不建议
```
❌ 全身 TXA — cancer 高凝 + VTE × 2 + IVC 滤网 → 微血栓/滤网血栓风险
例外：鼻出血 → TXA 5% 局部纱条填塞可考虑
```

#### C6. 利伐沙班逆转（危及生命大出血）
```
首选：andexanet alfa（国内未普及）
替代：4F-PCC 50 IU/kg ivgtt（50 kg → 2500 IU），10 min 内输完
辅助：维生素 K1 10 mg iv（证据弱）
警惕：本患者基线血栓事件风险高
```

### E. LMWH 方案（路径 B 启用时）

**首选 — 达肝素（CLOT 原方案）**
```
首月：200 IU/kg sc QD → 50 kg = 10,000 IU sc QD
2-6 月：150 IU/kg sc QD → 50 kg = 7,500 IU sc QD
肾调整：CrCl 20-30 减量 ~25%；< 20 改 UFH
监测：抗-Xa 峰值（注射后 4h）0.5-1.0 IU/mL
```

**次选 — 依诺肝素**
```
1 mg/kg sc q12h（50 kg → 50 mg sc q12h）
CrCl 15-30 → 1 mg/kg sc QD；< 15 → UFH
```

**国内常用 — 那屈肝素**
```
86 IU/kg sc q12h（50 kg → 4,300 IU sc q12h；0.4 mL）
CrCl < 30 → 减量 25-33% 或 UFH
```

**肾衰 / 高出血风险 / 需快速可逆 — UFH 泵入**
```
无 bolus；维持 18 IU/kg/h iv pump
监测 APTT q6h 目标 1.5-2.5× baseline 或 50-80s
中和：鱼精蛋白 1 mg / 100 IU UFH（过去 2h 累计量）
```

**鱼精蛋白逆转**：
- LMWH：1 mg 鱼精蛋白 / 100 抗-Xa IU LMWH（8h 内）；> 12h 不必中和
- UFH：1 mg / 100 IU UFH（过去 2h 内输注量）
- 单次上限 50 mg，缓慢 iv > 10 min

### F. HIT 评估（必做）

4Ts 评分（任何近期肝素暴露 + PLT 显著下降）：
- 血小板下降幅度 / 时间 / 血栓表现 / 其他原因
- ≥ 4 分 → 立即停所有肝素 + 查抗 PF4，启用：
```
阿加曲班 (Argatroban) 持续泵入
起始：2 μg/kg/min iv（无负荷）
肝功不全（Child B/C / TBil ↑）→ 0.5 μg/kg/min 起
监测：APTT 1.5-3.0× baseline（40-80s）
注意：APTT 受 DIC 影响；会延长 INR，影响后续华法林转换
替代：磺达肝癸钠 7.5 mg sc QD（出血状态慎用）
```

### G. 肿瘤治疗调整（MDT 决策）

| 用药 | 建议 |
|---|---|
| EGFR-TKI（吉非替尼/厄洛替尼/奥希替尼等） | 与肿瘤科商定继续 vs 暂停；疑血液毒性 → 暂停 1-2 周 |
| ALK / ROS1 抑制剂 | 同上 |

| 免疫检查点抑制剂 | 排除免疫性血小板减少 |

| **CLOT (Lee NEJM 2003)** | LMWH (达肝素) > VKA 用于 CAT 长期抗凝；VTE 复发 9% vs 17% |
| **CATCH (JAMA 2015)** | 替奈普素同样优于 VKA |
| **Hokusai-VTE Cancer (NEJM 2018)** | 依度沙班 non-inferior；GI 大出血 ↑（GI/GU 肿瘤慎用） |
| **SELECT-D (JCO 2018)** | 利伐沙班 VTE 复发 ↓ 但 CRNMB ↑ |
| **CARAVAGGIO (NEJM 2020)** | 阿哌沙班 non-inferior 且大出血未增（不含脑癌 / 急性白血病） |
| **ADAM-VTE (JTH 2020)** | 阿哌沙班 vs 达肝素：VTE 复发 0.7% vs 6.3% |
| **PREPIC2 (JAMA 2015)** | IVC 滤网 + 抗凝 vs 单纯抗凝**无获益**，可回收滤网 3 个月内取出 |
| **PATCH (Lancet 2016)** | 自发 ICH + 阿司匹林：输 PLT 反加重转归 |
| **ITAC 2022 / ASH 2021 / ASCO 2023** | 高出血风险（脑转移、近期 GI/GU 出血、严重血小板减少）→ LMWH 优先 |
| **ISTH DIC 2013 / EHA-ISTH 2024** | overt DIC 评分；治疗以原发病为本，按表型支持 |
| **AABB 2015 / BSH 2017** | PLT 阈值：一般 < 10；操作 < 50；ICH < 100 |
| **BCSH 2022** | Fib：大出血 ≥ 1.5；产科 / ICH ≥ 2.0 |
| **NICE-SUGAR (NEJM 2009)** | ICU 血糖 7.8-10 mmol/L |
| **TRICC / TRISS** | 限制输血 Hb 70；TBI / ACS 放宽 80-90 |
| **CRASH-3** | TBI 早期 3h 内 TXA（本患者不适用） |
| **SCARLET (2019)** | 重组 TM-α 在 sepsis-DIC 阴性 |
