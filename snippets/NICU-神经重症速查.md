# 神经重症速查

> 详见 `guidelines/NICU/NICU-TBI-SAH-ICH与癫痫管理.md`

## TBI BTF 阈值

| 参数 | 目标 |
|---|---|
| ICP | < 22 |
| CPP | 60–70 |
| PbtO₂ | > 20 |
| Na | 145–155（治疗中）|
| Glucose | 140–180 |
| 体温 | 35.5–37.5（避热） |
| SBP（按年龄） | 110 / 100 / 110 |

## ICP > 22 应对（SIBICC）

```
Tier 0: 头高 30°、镇静、Na 145–155、CPP 60–70
Tier 1: ↑镇静、EVD 引流、3% NaCl 250 mL bolus 或 mannitol 0.5 g/kg、PaCO₂ 35–38
Tier 2: NMBA、持续 HTS Na 150–155、↑ MAP
Tier 3: barbiturate coma、decompressive craniectomy、低温（refractory only）
```

## HTS vs Mannitol

| | 3% NaCl | Mannitol |
|---|---|---|
| Bolus | 250 mL | 0.25–1 g/kg |
| 容量影响 | 扩容 | 利尿 → 可能低血压 |
| 监测 | Na、Cl、Osm | 渗透压差 < 20 安全 |
| 选择 | refractory ICP / 低血压 | 容量过负荷者 |

## SAH 关键

- 动脉瘤 < 24–72 h coiling（ISAT）
- **Nimodipine 60 mg PO q4h × 21d**
- 未处理 → SBP < 160；处理后宽松
- 血管痉挛监测：TCD POD 3–14；避 hyponatremia
- DCI：euvolemia + induced HTN（弃 Triple-H）

## ICH 关键

- SBP 目标 **< 140**（不必降至 < 110）
- DOAC 逆转：dabigatran → idarucizumab；Xa → andexanet alfa / 4F-PCC
- 抗血小板逆转：**不输 plt**（PATCH 阴性）
- 微创外科：MISTIE-III 阴性，ENRICH 2024 阳性（< 60 mL lobar/basal ganglia）

## Status epilepticus 阶梯

```
0–5 min:  气道/循环
5–20 min: lorazepam 0.1 mg/kg IV / midazolam 10 mg IM
20–40 min: levetiracetam 60 mg/kg 或 fosphenytoin 20 mg PE/kg 或 valproate 40 mg/kg
> 40 min:  midazolam / propofol / pentobarbital infusion，目标 EEG burst-suppression
> 24 h:    ketamine、isoflurane，寻找病因
所有: cEEG 监测
```

## 心脏骤停后

- **目标 normothermia + 严格避热**（≤ 37.5）× 72 h（TTM2）
- 33–34 仅 selected（严重昏迷 / 难治性）
- 神经预后评估 ≥ 72 h 后，多模态

## 神经重症镇静顺位

1. Propofol（神经评估窗、ICP 控制）
2. Dexmedetomidine（不抑呼吸；ICP 控制弱）
3. Fentanyl/remifentanil（镇痛）
4. Pentobarbital（refractory ICP）
- 避免长 BZD（除 SE）
