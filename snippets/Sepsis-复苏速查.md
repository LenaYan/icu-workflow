# Sepsis 复苏速查

> 详见 `guidelines/sepsis/Sepsis-识别复苏与抗感染.md`

## Sepsis-3

- Sepsis：感染 + SOFA ↑ ≥ 2
- Septic shock：充分扩容后仍需 VP 维持 MAP ≥ 65 + 乳酸 > 2

## 1 h Bundle（SSC 2021）

- [ ] 测乳酸
- [ ] 血培养 ×2 + 病原筛查
- [ ] 经验性广谱抗生素（shock 立即；可能 sepsis 3 h 内决定）
- [ ] 30 mL/kg 平衡晶体（建议而非强制，按个体）
- [ ] MAP < 65 → 启动 NE

## 复苏目标

| 指标 | 目标 |
|---|---|
| MAP | ≥ 65 |
| 乳酸 | 6 h 内趋势下降，> 10–20% 清除 |
| 尿量 | ≥ 0.5 mL/kg/h |
| CRT | 改善（< 3 s） |

## Vasopressor 阶梯

```
NE 起步 0.05 μg/kg/min
  ↓ MAP < 65 持续
NE 滴定至 0.25 μg/kg/min
  ↓
加 vasopressin 0.03 U/min（不滴定）
  ↓
加 epinephrine 0.05–0.5 μg/kg/min（合并 LV 差）
  ↓ refractory（NE > 0.25 持续 ≥ 4 h）
hydrocortisone 200 mg/d（50 mg q6h 或持续输注）
± angiotensin II（如可及）
```

## 抗生素经验性选择

| 感染源 | 一线 | 加用 |
|---|---|---|
| HAP/VAP 高耐药 | piperacillin-tazobactam 4.5 g q6h（延长 4 h） 或 meropenem 1–2 g q8h | vancomycin / linezolid 覆 MRSA |
| 腹腔 | piperacillin-tazobactam 或 carbapenem | metronidazole（厌氧） |
| 尿源 | 头孢三代 → meropenem | aminoglycoside（短期联用） |
| 软组织/坏死性 | piperacillin-tazobactam + clindamycin（抑毒素）+ linezolid | 外科会诊 |
| CRBSI | vancomycin + 抗 G⁻ 覆盖 | 拔管 |

→ 48–72 h 培养指导降阶梯；β-lactam 持续/延长输注 + TDM。

## 不推荐 / 避免

- ❌ Vit C + thiamine + HC "cocktail"（LOVIT 阴性）
- ❌ 严格血糖控制 80–110（NICE-SUGAR）
- ❌ ScvO₂ 作为单一靶
- ❌ HFOV、HVHF CRRT
- ❌ 30 mL/kg 机械执行（个体化，CLASSIC/CLOVERS）
