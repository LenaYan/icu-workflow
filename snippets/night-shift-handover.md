# 夜班交班 · 床旁口袋卡

> **场景**：ICU 夜班接班 + 高危复评 + 升级路径
> **原则**：盯趋势不盯单点 · 把"观察"写成可执行动作 · 每个动作必带复评条件

## 1. 接班 5 问（每个床都要回答）

1. **谁最可能在夜里出事？**（不是"谁最重"）— 重点盯哪 3 个床？
2. **血管活性药**：当前剂量 + 6–12 h 趋势 + MAP 目标 + 灌注证据 + 反应性/耐受性
3. **呼吸机**：模式 / Vt(PBW) / Pplat / ΔP / PEEP / FiO₂ / 最近调参原因 + 调后 PaO₂/FiO₂ & PaCO₂
4. **乳酸 / 血气 / 尿量 / 电解质** — 报趋势不报单点
5. **pending = 时间 + 责任人 + 触发阈值 + 升级对象**

---

## 2. 四条生命线（每床每 2–4 h 过一遍）

| 线 | 关注点 |
|---|---|
| **氧合通气** | FiO₂ / PEEP / P/F / 呼吸功 / PaCO₂ / 分泌物 / 人工气道 |
| **循环灌注** | MAP + 升压药趋势 + 脉压 + 乳酸 + CRT + 皮温 + 意识 + 尿量 |
| **肾与液体** | 尿量 ↓ 鉴别：灌注 / 静脉淤血 / 腹压 / 导尿管 / 肾毒药 / AKI |
| **意识镇静** | 躁动/嗜睡/谵妄 → 低氧 / 高 CO₂ / 休克 / 感染 / 疼痛 / 撤药 / 代谢 / 镇静过量 |

---

## 3. 四个真正要盯的趋势

- **MAP**：看目标，更看达标代价（升压药在加吗？灌注改善吗？有缩血管代价吗？）
- **脉压**：变小 = 报警器（鉴别 低容量 / 心衰 / 张力性气胸 / 心包填塞 / PE / 过度 PEEP）
- **乳酸**：不降 = 问题没结束（不是"再补 500 mL"）
- **尿量**：是全身灌注 + 静脉回流问题，不是肾科问题

**斜率警报**（1 h 内任一发生 → 触发复评，不要"再观察"）：
- 升压药 0.05 → 0.15 µg/kg/min
- FiO₂ 40% → 70%
- 尿量 60 → 10 mL/h

---

## 4. 触发阈值公式

> **如果 X 在 Y 时间内达到 Z 趋势 → 做 A 复评 + 准备 B 干预 + C 时间通知 D 人**

### 六大触发场景速查

| 场景 | 触发信号 | 立刻复评 | 升级动作 |
|---|---|---|---|
| 氧合下降 | FiO₂/PEEP ↑、P/F ↓、呼吸功 ↑、意识变差 | 管路/气囊/分泌物、血气、肺超或 CXR、气胸/肺不张/肺水肿/PE/感染 | 通知上级；HFNC/NIV 失败的插管方案；严重低氧讨论俯卧位 |
| 低血压 / 升压加量 | MAP < 目标、NE 持续上调、脉压 ↓、乳酸 ↑、尿量 ↓ | 休克分型、PLR/小量挑战 + VTI、心超/肺超/VExUS、出血/感染源/心律 | 反应性 + 耐受才补液；张力低优先升压药；心源/阻塞性早叫专科 |
| 乳酸不清 | 乳酸不降或反升，合并升压 ↑ 或尿量 ↓ | 氧输送、灌注、感染源、出血/缺血、肝肾清除、药物、惊厥 | 写明复查时间；源控/抗菌/影像/外科介入阈值；不简单等同缺液 |
| 少尿 | 尿量 < 0.5 mL/kg/h 趋势 + 肌酐/K⁺/酸中毒恶化 | 导尿管、入出量、MAP/灌注、VExUS/腹压、肾毒药、电解质血气 | 高钾/难治酸中毒/容量过负荷/尿毒症 → 提前通知肾科评估 RRT |
| 躁动 / 镇静变深 | RASS 偏离目标、突然躁动、谵妄、嗜睡 | ABC、疼痛、血气、血糖、电解质、感染、撤药、药物蓄积 | 先纠正生理问题再调镇静；勿用镇静掩盖低氧/高 CO₂/休克 |
| pending 没时间点 | 血气/影像/复查/电解质/换管/会诊无 deadline | 查医嘱、执行人、完成时间、结果回报路径 | 每项 pending 写明"未完成谁追、异常通知谁" |

## 5. 接班 30 分钟床旁脚本（不要先坐下写病历）

1. **看屏幕**（只看趋势）：BP、升压药、HR、SpO₂、FiO₂、PEEP、RR、尿量、温度、镇静评分
2. **看管路**：插管深度/固定、呼吸机管路冷凝水、CVC/A-line、引流管、导尿管、泵速、剩余药量
3. **问护士**：今晚最担心哪个床？白天最不稳定哪个？哪些 pending 易漏？哪些家属/会诊会在夜里？
4. **写触发阈值**：每个高危床至少 1 条 "如果…就…"。**没有触发阈值的"严密观察" = 没有交班**。

## 6. SBAR 电话模板（给上级 — 先讲你担心什么，不要从病史讲起）

**S**：X 床主要问题 ___，过去 ___ h 趋势在变坏。
**B**：基础病 / 入 ICU 原因 / 当前支持：呼吸 ___，循环 ___，肾脏 ___，感染/源控 ___。
**A**：判断更像 ___（低容量 / 分布性 / 心源性 / 阻塞性 / 呼吸衰竭 / AKI 进展），依据 ___。
**R**：已做 ___；准备 ___；如果 ___ min 内不改善，建议 ___，请您 ___ 内床旁评估。

## 7. 高危复评进展记录模板（7 行填空）

```
1. 当前主要风险：氧合/通气 ___；循环/灌注 ___；肾/液体 ___；意识/镇静 ___
2. 趋势：MAP ___；血管活性药 ___；乳酸 ___；尿量 ___；P/F ___；PaCO₂/pH ___
3. 床旁：气道/管路 ___；肺超 ___；心超/VExUS ___；导尿/引流 ___
4. 判断：最可能问题 ___；主要鉴别 ___
5. 处理：已完成 ___；待完成 ___
6. 触发阈值：若 ___，则 ___，并通知 ___
7. 复评：___ 点复评 ___；结果回报 ___
```

## 8. 最小 4 行清单（每床必过）

| 维度 | 自问 |
|---|---|
| **风险** | 这个床今晚最可能死于什么？ |
| **趋势** | 过去 6–12 h 哪条曲线在变坏？ |
| **阈值** | 到什么程度必须叫人 / 复查 / 升级治疗？ |
| **复评** | 做完一个动作后，几点看什么结果？ |

---

## 9. 易犯错误（自查）

- ❌ 低血压就补液 → 先问休克分型 + 反应性 + 耐受性（`Fluid_Responsiveness` + `VExUS_Score`）
- ❌ 只看 MAP 不看灌注 → "循环稳定"必须可验证（MAP / NE / 乳酸趋势 / 尿量 / 皮温 / 意识）
- ❌ 等指标越线才处理 → 趋势变坏就要触发复评
- ❌ 处理后不复评 → 补液 → 看乳酸+肺水；调 PEEP → 看 BP+Pplat；加镇静 → 看 PaCO₂+谵妄；加升压 → 看灌注+尿量

---

## 10. 不要等出事再做

- **动脉通路**：升压药频调、无创血压不可信、频繁血气 → 早置管
- **血气**：每次必答 — 氧合够否、通气够否、酸碱能否解释、乳酸+电解质有无危机
- **POCUS**：低血压/低氧分诊到 左心泵衰/右心负荷/容量/淤血/肺水/气胸/胸腔积液/肺实变/DVT
- **气道预案**：HFNC/NIV 边缘、氧合渐降、呼吸功 ↑、意识变差 → 预氧合 + 循环准备 + 首选/备选工具 + 求援路径前置
