# AKI 分期与处置速查

> 详见 `guidelines/AKI/AKI-诊断分期与防治.md`

## KDIGO 分期

| 分期 | SCr | 尿量 |
|---|---|---|
| 1 | 1.5–1.9× baseline 或 ↑ ≥ 0.3 mg/dL | < 0.5 mL/kg/h × 6–12 h |
| 2 | 2.0–2.9× | < 0.5 ≥ 12 h |
| 3 | ≥ 3.0× / ≥ 4.0 mg/dL / RRT | < 0.3 ≥ 24 h 或无尿 ≥ 12 h |

## 病因鉴别速查

| 线索 | 提示 |
|---|---|
| FENa < 1%（无利尿剂） | pre-renal |
| FEUrea < 35%（用利尿剂） | pre-renal |
| Muddy brown casts | ATN |
| RBC casts | GN |
| WBC casts + eosinophil | AIN |
| 肾 US 积水 | post-renal |

## FST（呋塞米压力试验）

呋塞米 1.0–1.5 mg/kg IV → 2 h 尿量 < 200 mL → 进展至 stage 3 / 需 RRT 风险高

## 启动 CRRT — AEIOU

- **A** 难治性酸中毒（pH < 7.15）
- **E** K⁺ > 6.5 难治
- **I** 中毒（lithium / metformin / salicylate / valproate）
- **O** 难治性容量过负荷
- **U** 尿毒症并发症

→ 详细处方见 `snippets/CRRT-处方速查.md`

## 防 CA-AKI

- 高危：eGFR < 30 / 糖尿病肾病 / 心衰
- IV NS 1 mL/kg/h × 12 h 前后
- 造影剂用量最小化、低渗剂
- ❌ NaHCO₃ 水化 / NAC（PRESERVE 阴性）

## 容量与血压

- 平衡晶体优先（SMART / PLUS）
- 避免累积液体过负荷 > 10%
- MAP：通常 ≥ 65，慢性 HTN ≥ 75–80

## 药物急性期处理

| 必停 | NSAIDs |
|---|---|
| 暂停 | ACEI/ARB（恢复期重启）、SGLT2i（恢复期重启） |
| TDM | vancomycin、aminoglycoside、polymyxin、β-lactam (CRRT) |
| 减量 | 据 GFR / CRRT effluent rate |

## 恢复期

- 3 月内肾科随访
- SGLT2i 恢复期启动（无禁忌）
- 复测 eGFR、UPCR/UACR 3–6 月
