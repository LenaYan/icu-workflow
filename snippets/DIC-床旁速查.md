# DIC 床旁速查

> 详见 `literature/topics/trousseau-syndrome-CAT.md`；指南：ISTH 2013、EHA-ISTH 2024、JSTH 2024

## 一、识别 — ISTH overt DIC 评分（前提：存在 DIC 相关基础疾病）

| 项目 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| PLT (×10⁹/L) | ≥ 100 | 50-99 | < 50 | — |
| D-dimer / FDP | 无升 | 中度升（< 5×） | — | 显著升（≥ 5×） |
| PT 延长（s） | < 3 | 3-6 | ≥ 6 | — |
| Fib (g/L) | ≥ 1.0 | < 1.0 | — | — |

- **≥ 5 分 → overt DIC**；< 5 分 + 临床高度怀疑 → 24h 复评（non-overt）
- 同时记录：临床出血部位、微血栓征（指端坏死、肾、神经）

## 二、分型与对应表型

| 类型 | 表型 | 典型病因 | 实验室 | 治疗重心 |
|---|---|---|---|---|
| **高凝型** | 微血管栓塞 > 出血 | 早期 sepsis、实体瘤（早期 Trousseau） | Fib 正常/↑、D-dimer ↑↑、PLT 轻降 | 抗凝（LMWH/UFH） |
| **消耗型** | 出血 + 微血栓并存 | 肿瘤进展、产科（HELLP、AFE）、晚期 sepsis | Fib ↓、PLT ↓、PT 延长、D-dimer ↑↑ | 替代支持 + 病因 |
| **纤溶亢进型** | 出血为主 | **APL**、前列腺癌、严重肝病、AAA 修复 | Fib ↓↓、纤溶酶 ↑、α2-antiplasmin ↓ | 病因 + 谨慎抗纤溶 |
| **大出血型** | 创伤、产科 PPH | DIC 与出血复合 | 全线 ↓ | 大量输血方案（MTP） |

## 三、必查（入室即开）

- [ ] 血常规 + 网织（**PLT、Hb、schistocytes**）
- [ ] PT / INR / APTT / **Fib / D-dimer / FDP**
- [ ] AT-III、Protein C / S（条件时）
- [ ] **外周血涂片**（schistocytes ≥ 1% 提示 MAHA）
- [ ] LDH、间接 Bil、结合珠蛋白、Coombs（鉴别 TMA）
- [ ] 肝肾功、白蛋白、电解质
- [ ] 病因检查（培养、肿瘤标志、影像、骨髓象指征时）

## 四、治疗 — 病因优先 + 表型支持

### A. 病因（最关键）
- 感染：源控 + 经验性抗生素（SSC 1h bundle）
- 肿瘤：化疗 / 靶向 / 手术 / 全反式维甲酸（APL）
- 产科：终止妊娠 / 胎盘娩出
- 创伤：损伤控制手术 + 大输血方案

### B. 表型支持医嘱（**有出血时**）

```
血小板：PLT < 50 + 出血 → 输 1 治疗量；ICH 目标 ≥ 100
纤维蛋白原：Fib < 1.5 + 出血 → 人纤维蛋白原 4 g 或冷沉淀 10 U
            （ICH / 产科目标 ≥ 2.0）
FFP：PT/APTT > 1.5× ULN + 出血 → 10-15 mL/kg
红细胞：Hb < 70（一般），< 80（缺血 / SAH 痉挛期）
AT-III：AT < 50% + 出血 → 200-300 IU iv（日本指南推荐，证据弱）
```

> **预防性输注**（无出血、无操作）阈值很低：PLT < 10、Fib < 1.0；不要"看到低就输"

### C. 抗凝（**高凝表型 / 微血栓 / VTE**）

```
LMWH（首选，cancer-DIC 优）
  达肝素 200 IU/kg sc QD  或
  依诺肝素 1 mg/kg sc q12h  或
  那屈肝素 86 IU/kg sc q12h
UFH 18 IU/kg/h iv pump（肾衰、需快速可逆）
监测：抗-Xa / APTT；PLT 轻降至 50 仍可继续，< 50 减量
```

### D. **不常规用 / 禁用**

- ❌ **TXA（氨甲环酸）**：高凝表型 / VTE / 滤网在位 → 微血栓加重；除非**纤溶亢进型 + 出血明确**
- ❌ **rFVIIa**：限创伤大出血常规失败后救援；DIC 中加重微血栓
- ❌ **重组血栓调节蛋白（TM-α）**：SCARLET 2019 阴性，国际未推荐（日本批准）
- ❌ "**DIC cocktail（肝素 + AT + FFP）经验性套餐**"

## 五、并发症监测

| 并发症 | 监测 | 阈值 |
|---|---|---|
| ICH | q1-4h GCS、瞳孔；24h、72h CT | 任何 GCS↓ ≥ 2 → CT |
| PE | SpO₂、TTE、必要 CTPA | 突发低氧 + RV strain |
| 急性肾损伤 | 尿量、Cr q24h | 微血栓性 AKI 提示 TMA |
| 微血栓 | 指端、皮肤、肠系膜（乳酸）、神经 | 任何新发缺血→升级讨论 |
| HIT | PLT 趋势 + 4Ts | ≥ 4 立即换阿加曲班 |

## 六、Red Flags — 立即升级 / 多学科

- DIC 评分动态上升 ≥ 2
- Fib < 1.0 持续 + 输注后无升 → AT-III 替代 + 强化病因控制
- PLT 输注后 CCI < 7.5 → 排 HIT / ITP / 同种免疫
- 新发神经体征 / 指端缺血 / 急性肾衰
- 大量输血（24h 内 PRBC > 10 U）— 启动 MTP 协议

## 七、常用计算

```
ISTH score 算法（在线 / 床旁卡）
CCI = (输后 PLT − 输前 PLT) × BSA / 输注 PLT 数量（×10¹¹）
       1h CCI ≥ 7.5、20h ≥ 4.5 视为有效
Fib 升量预估 ≈ 给药剂量(g) / 0.04 / 体重(kg)
冷沉淀 1 U/10 kg ≈ ↑ Fib 0.5-0.7 g/L
单采血小板 1 治疗量 ≈ ↑ PLT 30-50 ×10⁹/L
```
