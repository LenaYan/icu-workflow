# ECMO / IABP / Impella 床旁速查

## SCAI shock 分期速辨
| 期 | 一句话 | 处理 |
|---|---|---|
| A 风险 | 无 CS | 监测 |
| B 起始 | SBP↓ 但乳酸正常 | 单药 NE |
| C 经典 | 低灌注 + 需药 | 多药 / IABP |
| D 恶化 | C 但持续升级 | MCS 准备 |
| E 终末 | CPR / 难治 | E-CPR / VA-ECMO |

## 关键数字
| 参数 | 目标 |
|---|---|
| MAP | ≥ 65（HTN/CKD 70+） |
| CI | ≥ 2.2 L/min/m² |
| SvO₂ / ScvO₂ | ≥ 60 / ≥ 65 |
| Lactate | < 2 / 24h 内清除 |
| UO | ≥ 0.5 mL/kg/h |
| CPO = MAP×CO/451 | ≥ 0.6 W |
| PAPi = (PASP−PADP)/RAP | ≥ 1.0（< 1.0 RV failure） |

## 一、设备选择速查

| 临床场景 | 首选 | 备选 | 证据 |
|---|---|---|---|
| AMI-CS, 单纯 LV | **Impella CP** | IABP | DanGer Shock 2024 (NNT 8) |
| AMI 机械并发症 (VSD, 急 MR) | IABP 桥接 | Impella | IABP-SHOCK II 已否定常规 |
| 难治 CS, 全心衰 | **VA-ECMO** | + LV vent | 选择性使用 (ECLS-SHOCK 阴性) |
| 心肺联合衰 (ARDS-CS) | VA-ECMO | V-AV configuration | |
| RV failure 主导 | **Impella RP** / ProtekDuo | iNO + 容量管理 | |
| 高危 PCI 保护 | **Impella CP** | IABP | PROTECT II/III |
| 心脏术后短期支持 | Impella / IABP | VA-ECMO | 先排除外科原因 |
| E-CPR | **VA-ECMO** | — | ARREST/Prague OHCA 中心化 |
| 严重 ARDS | **VV-ECMO** | — | EOLIA, CESAR |

## 二、IABP 速查

### 适应（窄）
- AMI 机械并发症桥接手术
- 难治心绞痛
- 高危 PCI 保护

### 禁忌
- 重度 AR
- 主动脉夹层
- 严重 PAD
- 大动脉瘤

### 触发与时序
- 1:1（充气在重搏切迹、放气在 R 波前）
- 难治心律失常 → 压力触发
- 检查：搏动波形（增压 ↑ 收缩压 ↓ 舒张压 ↑）

### 床旁监测
| 项 | 频率 |
|---|---|
| 远端肢体灌注、足背 | q1h |
| 尿量 | q1h（球囊位置阻断 RA 可致 UO↓） |
| 血小板 | q12h |
| 气体瓶余量 | 每班 |
| 胸片确认球囊位置（左锁骨下动脉远 1–2 cm 至肾 A 上方） | 每日 |

### 撤离
- inotrope 减至最低
- IABP 2:1 → 3:1，观察 30–60 min
- 撤管：手压 30 min + 加压包扎 6h

## 三、Impella 速查

### 型号
| 型号 | 流量 | 入路 | 维持时长 |
|---|---|---|---|
| 2.5 | 2.5 L/min | 股动脉 | < 6h（PCI 期间） |
| **CP** | 3.5 L/min | 股动脉 | 4–5 d |
| 5.0 / 5.5 | 5.0–5.5 L/min | 外科切开 | 14 d |
| RP | 4 L/min | 股静脉→PA | 14 d |

### 关键参数
- **P-level** P0–P9（流量挡）
- **Motor current** 反映 LV 卸载情况
- **Placement signal** 位置波形（动脉 vs 心室）
- **Purge flow** 4–30 mL/h（防泵头血栓，dextrose-肝素）

### 禁忌
- 重度 AR
- 机械瓣（主动脉）
- LV 血栓
- VSD 大缺损
- 主动脉夹层
- 严重 PAD

### 床旁监测
| 项 | 频率 | 警报 |
|---|---|---|
| 位置波形 | 连续 | 平坦 → 移位 |
| Motor current | 连续 | 突变 → 抽吸 / 移位 |
| Purge 压力 | 连续 | 升高 → 血栓风险 |
| 溶血标志 (LDH, plasma free Hb) | q12h | LDH > 700 警惕 |
| ACT | q4h | 160–180 |
| 远端灌注、NIRS | q1h | |

### 抽吸事件 (suction)
- 表现：流量骤降 + motor current 漂移
- 原因：容量不足、LV 塌陷、位置过深
- 处理：暂时降 P-level、补容量、echo 重定位

## 四、VA-ECMO 速查

### 初始处方（成人）
| 项 | 数值 |
|---|---|
| Pump flow | 50–80 mL/kg/min（70kg ≈ 3.5–5.5 L/min） |
| Sweep gas (L/min) | 起 = pump flow（1:1） |
| FdO₂ | 0.6 起 |
| PaO₂（**右桡**） | 60–150（避 > 200） |
| PaCO₂ | 35–45；高碳酸恢复期 ΔPaCO₂ ≤ 20 mmHg / 24h |
| MAP | ≥ 65 |
| Hb | ≥ 8（出血 9–10） |
| PLT | ≥ 50（出血 ≥ 80） |
| ACT / anti-Xa | 180–220 / 0.3–0.7 |
| SvO₂ | ≥ 65（drainage 取血） |

### 监测 q1h
- [ ] 右桡动脉 SpO₂ + 床旁 ABG（**不是股 A**）
- [ ] 下肢 SpO₂ + 触诊足背 / 胫后
- [ ] 脑 NIRS + 下肢 NIRS
- [ ] 尿量
- [ ] 引流压（pre-pump 负压不应 < -100 mmHg）
- [ ] 跨膜压差 (∆P 膜)
- [ ] 管路抖动 / 抽吸（提示容量不足或引流不畅）

### Harlequin (N/B) 综合征识别
**右桡动脉 PaO₂ 低 + 股动脉 PaO₂ 正常 + LV 心排恢复**
- 病理：差氧合的自身血流灌注上半身，ECMO 氧合的血流灌注下半身
- 处理选项：
  1. ↑ 自身肺氧合：插管 / 优化 LPV / iNO
  2. 换插管位（V-A → V-AV：颈内追加回流）
  3. 中心插管（升主动脉回流）

### LV 卸载 (LV vent) 触发
- AV 持续关闭
- 肺水肿 / 严重 B-line
- LV 膨胀（LVEDD ↑、心内血栓风险）
- PCWP > 20

**卸载选项**：IABP（最简）、Impella、PA 引流、房间隔造口（穿刺）

### 撤离 ECMO
**前提**：
- Lactate < 2、MAP 维持、UO 充足
- LVEF 改善、自身脉压恢复（动脉波形不再平坦）

**Trial**：
- 关闭气泵 2–3 min（**只关 sweep gas，不关 pump**）评估自身肺
- Pump flow 渐减至 1.5 L/min × 30–60 min
- 评估：LVOT-VTI > 12 cm、TAPSE > 12 mm、MAP 不降、ScvO₂ 不降
- 通过则提高 ACT → 拔管

**失败标准**：MAP ↓ > 10、乳酸 ↑、需 inotrope 上调 → 恢复流量 24h 再试

## 五、VV-ECMO 速查（ARDS）

### 适应 (RESP / EOLIA-like)
- P/F < 50 mmHg ≥ 3h，**或** P/F < 80 ≥ 6h
- 难治高碳酸：pH < 7.25 + PaCO₂ ≥ 60 ≥ 6h on optimal vent
- **常规 LPV + prone + 肌松失败**之后

### 禁忌（相对）
- 机械通气 > 7 d on high settings
- 多器官衰
- ICH / 出血风险高
- 不可逆肺病无移植路径

### 配置
- 标准：股 V（drainage）+ 颈 V（return）；或 dual-lumen 颈内
- Sweep gas 调 CO₂，FdO₂ + flow 调 O₂

### 通气策略（"肺休息"）
- Vt 2–4 mL/kg PBW（**ultra-LPV**）
- RR 10
- Pplat ≤ 25, ΔP ≤ 14
- PEEP 10–14
- FiO₂ ≤ 0.5

### 撤离 VV-ECMO
- FdO₂ → 0.21 + 评估 SpO₂、PaO₂ 维持
- Sweep gas → 0（保留 pump flow 防血栓）
- 自身肺通气评估 6–24h → 拔管

## 六、紧急情况速处

| 情景 | 第一动作 | 接下来 |
|---|---|---|
| ECMO 流量骤降 | 检查患者容量 / 引流管打折 / 抽吸 | 补液 250 mL；echo |
| Pump 报警 | 查管路 / Hb / ACT | 必要时换泵 |
| 严重溶血 (LDH > 1000) | 检查泵头 / 管路扭曲 | 换泵头 |
| Harlequin | 测右桡 ABG 确认 | 见上 |
| 出血 (ECMO 上) | ACT 下调 / TXA / 输血 | 外科会诊；hemostasis |
| ECMO 上心跳骤停 | **不按压**（管路损伤风险） | 提高 flow；除颤；找原因 |
| 插管处搏出 | 直接按压 + 紧急外科 | 不能用 tourniquet |
| HIT 怀疑 | 4Ts 评分 | 改 argatroban / bivalirudin |
| 肢端缺血 | 立即评估 DPC | 加 DPC / 外科会诊 / 换路径 |

## 七、抗凝速查

| 设备 | 默认 | 监测 | 备选（HIT / 出血） |
|---|---|---|---|
| IABP | 不必常规（短期）；UFH 低剂量长期使用 | APTT 50–70 | — |
| Impella | UFH purge + 全身 | ACT 160–180 | bivalirudin（HIT） |
| VA-ECMO | UFH | ACT 180–220 / anti-Xa 0.3–0.7 | argatroban / bivalirudin |
| VV-ECMO | UFH（出血风险 ↑ 可短期不抗凝） | ACT 160–200 | argatroban |

## 八、关键试验一行版（口袋记忆）
- **DanGer 2024** — Impella ↓死亡 in STEMI-LV-CS
- **ECLS-SHOCK 2023** — VA-ECMO 在 AMI-CS 不获益
- **ECMO-CS 2023** — 早期 VA-ECMO 在 CS 不获益
- **IABP-SHOCK II 2012/19** — IABP 在 AMI-CS 不获益
- **EOLIA 2018** — VV-ECMO 在 sARDS 有获益（Bayesian 后验）
- **CESAR 2009** — 中心化 ECMO 改善 ARDS 生存
- **OptimaCC 2018** — NE > E
- **SOAP II 2010** — 多巴胺 > 死亡（心源性亚组）
- **DOREMI 2021** — milrinone = dobutamine
- **TTM2 2021** — 33 vs 36–37.5 无差异
