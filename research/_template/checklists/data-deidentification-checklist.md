# 数据去标识化 checklist
> 必须在数据进入 `data/derived/` 与任何分析脚本之前完成。
> 同时遵循 HIPAA Safe Harbor §164.514 与本院 IRB 要求。

## A. 直接标识符 — 必须删除或哈希
- [ ] 姓名（全名、首字母组合、罕见昵称）
- [ ] 身份证号 / 护照
- [ ] 病案号、住院号（保留派生整数 ID `pid`，原 ID 不留）
- [ ] 手机号、座机、传真
- [ ] 邮箱
- [ ] 完整家庭住址（街道+门牌；可保留省级）
- [ ] 邮政编码（精确 5 位 → 截断到前 3 位或删除）
- [ ] 设备序列号（ECMO、CRRT、呼吸机、植入物）
- [ ] DICOM 影像 PatientName/PatientID/AccessionNumber（用 DICOM anonymizer）
- [ ] 床号（如外发数据）
- [ ] 健康卡号、保险号
- [ ] 雇主、学校、单位名
- [ ] 车牌号
- [ ] 全脸照片、可识别影像
- [ ] 生物识别（指纹、声纹、眼底）
- [ ] IP 地址、账号 ID

## B. 间接标识符 — 处理或粗化
- [ ] 出生日期 → 入科时年龄（连续）或年龄段
- [ ] 所有日期 → 偏移（同一患者保持时间差）或截断到年-月
- [ ] 死亡日期 → 同上
- [ ] 入科 / 出科 / 手术 / 操作日期 → 入科为 t=0，相对天数
- [ ] 罕见诊断 / 罕见手术 → 评估是否会单独识别（k-anonymity）
- [ ] 罕见职业、罕见国籍：审慎保留
- [ ] 极端年龄（> 89 y）→ 折叠为 "≥90"

## C. 文本字段（病程、查体、影像报告）
- [ ] 移除自由文本中的：姓名、亲属姓名、医师姓名、单位
- [ ] 用 NLP 工具（Philter、Presidio 中文版）+ 手工抽查
- [ ] 抽样 5–10% 人工复核
- [ ] 保留临床信息，去除身份信息

## D. 重新身份识别风险评估
- [ ] 计算 k-anonymity（每条记录在准标识符组合上至少与 k-1 条相同）
- [ ] 评估罕见组合（性别+年龄+诊断+科室）是否会单独识别
- [ ] 与 IRB 协商可接受的 k 值（常用 k=5 或 k=10）

## E. 输出与共享
- [ ] 任何 figure / table 不出现单个患者可识别信息
- [ ] case description（病例报告）需单独 IRB 同意 + 患者书面同意
- [ ] 公开数据（如 Zenodo、Figshare）必须是 fully de-identified

## F. 文件与流程
- [ ] 原始数据存于受控位置（科室服务器 / 加密硬盘），不进 git
- [ ] `data/raw/` 已在 `.gitignore` 中
- [ ] 派生数据 `data/derived/` 也在 `.gitignore` 中
- [ ] 仅 `data/data-dictionary.md` 进 git
- [ ] 映射表（原 ID ↔ pid）单独加密存储，仅 PI/数据管理员可访问
- [ ] 完成日期 / 责任人记录于 `data/data-dictionary.md` 元信息
