# 评分细则：p1-htg-ap-d4

> 总分 100。 lint（D 类）由 `scripts/check_case_doc.py` 机械执行；A/B/C 类由人工或全新上下文的 sub-agent 对照 `gold-key.md` 逐条判定。

## 计分

| 类别 | 权重 | 规则 |
|---|---|---|
| A 必算项 | 20 分 | 每项 5 分；算了但无敏感性分析（A1/A3 要求时）得 3 分 |
| B 必抓项 | 40 分 | 每项 4 分；提到但判断方向错误或无论证得 2 分 |
| C 越界项 | −10 分/条 | 扣分项；越界内容若已显式标注「指南外推/推理」并说明依据链，减半（−5） |
| D 引用项 | 20 分 | lint 0 error 得满分；每条 error −5，扣完为止 |

## 通过线

- **≥ 80 分且 C 类无未标注越界**：通过，可归档
- **60–79 分**：修订后重评
- **< 60 或出现未标注越界**：不通过，需查流程哪一步失效（检索 / 计算 / 回核）

## 判定注意事项

- A 类只认文档中写出的计算过程与数值，"提及 ROX 概念但未计算"不得分
- B 类"提到"要求有处置含义，仅在问题清单里罗列而无分析不得满分
- C 类判定以指南字面范围为界；模型对边界有异议时，须在文档中写出依据链，由评分者判断标注是否充分
- 对比类产出（多文档对比）不适用本 rubric，按 `analysis-compare` skill 的规则单独评
