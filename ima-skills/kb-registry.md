# ima 知识库注册表（检索路由用）

> 用途：`ask_knowledge_base` 需要 `cookie_knowledge_base_id`，本表把各库 ID 与检索角色写死，**模型不必每次会话重新 `list_knowledge_bases_full`**。
> 上传归档的 folder_id 对照见 `kb-folder-ids.md`（本文件只管"查"，不管"传"）。
> ID 会随订阅变化，新增/退订知识库后更新本表。

## 检索总规则

1. **准则类问题（指南推荐、剂量、阈值、适应证）默认先查 ima，不先 WebSearch**：按下表角色顺序查；ima 无覆盖或 MCP 报 600001 时才降级 WebSearch / 本地 `guidelines/` 笔记，并在输出中声明证据来源降级。
2. **单次只查一个库**：同一问题按优先级依次查多个库，不要只查一个就下结论。
3. **RAG 回答只是检索入口**：剂量、推荐等级、阈值等关键数字必须用返回 references 中的 `media_id` 调 `get_media_info` 回原文核对；拿不到原文的标注「未核对原文」。
4. **冲突处理**：订阅库与自有库/本地 `guidelines/` 笔记结论冲突时，并列呈现并提示用户，不自动采信任一方。
5. **禁止补全**：检索不到的内容写「知识库未覆盖，建议查原文」，禁止凭记忆补剂量或推荐等级。
