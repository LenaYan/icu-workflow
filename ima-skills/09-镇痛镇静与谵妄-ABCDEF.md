# Skill：镇痛镇静与谵妄（ABCDEF）

## 适用场景

- RASS 评分偏离目标（过深 RASS ≤ -3 或过浅 RASS ≥ +1）需要调整镇静方案
- CAM-ICU 阳性或谵妄高风险患者的评估与防治
- 脱机前（SAT/SBT 前）的镇静策略调整与每日唤醒执行
- 神经重症患者（TBI、SAH、ICH、癫痫持续状态）镇静与神经查体的权衡
- 血流动力学不稳定或肝肾功能异常时的镇静镇痛药物选择

## 需要用户提供的信息

- 当前 RASS、CAM-ICU、疼痛评分（CPOT 或 NRS）
- 当前镇静镇痛药物、剂量、累计用药时长
- 血流动力学状态：MAP、血管活性药剂量、心率
- 肝肾功能：ALT/AST/胆红素、肌酐/eGFR、是否 CRRT
- 主要诊断与特殊场景：ARDS 严重程度（P/F）、ICP 情况、是否癫痫持续状态、是否需要保留神经查体
- 脱机进展：是否已做 SAT/SBT、失败原因

## 工作流程

1. **明确镇静镇痛目标**：默认轻镇静 RASS -2~0；先判断是否存在深镇静适应症（严重 ARDS 需 NMB 或俯卧位、颅内高压、癫痫持续状态、重症哮喘持续状态、目标温度管理等），有则设定对应深镇静目标并注明预计时长。
2. **评估镇痛是否充分**：先查 CPOT/NRS，遵循 analgesia-first 原则——先优化镇痛再调镇静，避免用镇静药掩盖疼痛。未控制的疼痛是躁动的首要可逆原因。
3. **评估脏器功能与血流动力学**：低血压/休克倾向选丙泊酚需减量缓慢滴定或改用右美托咪定；肝功能不全慎用咪达唑仑与阿片类蓄积；肾功能不全/CRRT 注意吗啡活性代谢物蓄积（优先芬太尼/瑞芬太尼）。
4. **神经重症单列判断**：需要保留神经查体（GCS、瞳孔）者，优先短效可唤醒方案（丙泊酚或右美托咪定），避免咪达唑仑持续泵注；颅高压者镇痛镇静本身就是 ICP 一线治疗组成部分，目标转向脑灌注（CPP 60-70 mmHg），可接受深镇静。
5. **制定药物选择与滴定方案**：按输出格式填表，起始量取低限，注明滴定步长与复评间隔。
6. **安排 SAT/SBT 联动**：每日评估 SAT 条件（无活动性癫痫、无颅高压危象、FiO2/PEEP 达标、血管活性药可耐受），SAT 通过即接 SBT，两者绑定执行。
7. **谵妄评估与防治**：CAM-ICU 每日评估；先执行非药物措施（早期活动、睡眠保护、视听辅助、家属陪伴、纠正诱因），药物仅用于对自身/他人构成危险的严重躁动或幻觉，不常规预防性使用氟哌啶醇/喹硫平。
8. **ABCDEF bundle 核查**：逐项核对当日 bundle 执行情况，输出缺口项与改进动作。

## 输出格式

**第一部分：目标设定**

```
镇静目标：RASS ___ （轻镇静 -2~0 / 深镇静 -4~-5，理由：___）
镇痛目标：CPOT < 3 或 NRS ≤ 3
谵妄目标：CAM-ICU 阴性；每日 2 次筛查
```

**第二部分：药物方案表**

| 药物 | 角色 | 起始量 | 滴定方案 | 目标/停药触发 | 主要监测 |
|---|---|---|---|---|---|
| 芬太尼/瑞芬太尼 | 镇痛基础 | （按体重与肾功能给出） | 每 30-60 min 按 CPOT 调整 | CPOT < 3 | 呼吸抑制、肠麻痹 |
| 丙泊酚 | 镇静首选之一 | 低起始缓慢上调 | 每 10-15 min 滴定 | RASS 达标 | MAP、甘油三酯、PRIS 风险（>65-70 µg/kg/min 或 >48-72 h） |
| 右美托咪定 | 轻镇静/谵妄高危/需唤醒 | 不推荐负荷量或减量负荷 | 按 RASS 滴定 | 可交流、可唤醒 | 心动过缓、低血压 |
| 咪达唑仑 | 仅限癫痫持续状态/短期深镇静 | 最小有效量 | 尽量避免 >48 h | 尽快转换为短效药 | 蓄积、谵妄风险、苏醒延迟 |

> 神经重症场景：需保留神经查体者镇静目标设为可唤醒（RASS 0~-1），优先丙泊酚或右美托咪定，避免咪达唑仑；颅高压者深镇静本身是 ICP 阶梯治疗一环，目标改为 CPP 60-70 mmHg 与 ICP < 22 mmHg，允许暂停每日唤醒并注明暂停理由。

**第三部分：SAT/SBT 联动**

```
SAT 条件核查：□无活动性癫痫 □无 ICP 危象 □FiO2 ≤ __/PEEP ≤ __ □血管活性药可耐受
SAT 通过 → 立即 SBT 30-120 min；失败则恢复前一剂量 50% 起始，记录失败原因
```

**第四部分：ABCDEF 每日核查清单**

- A（镇痛与躁动评估）：CPOT/NRS + RASS 每 4 h 记录
- B（SAT + SBT）：每日执行，记录结果与失败原因
- C（镇痛镇静药物选择）：短效优先，避免苯二氮卓常规泵注
- D（谵妄评估与管理）：CAM-ICU 每日 2 次；非药物措施优先
- E（早期活动）：评估活动等级，制动需注明理由
- F（家属参与）：探视/沟通/决策参与情况

## 知识库与证据规则

- 你只基于 ima 知识库内文档作答，锚定文档：SCCM PADIS 2018 + PADIS 2025 focused update、中国神经重症镇静镇痛共识 2024、ARDS 相关指南（ESICM ARDS 2023 / ATS ARDS 2024，用于深镇静与 NMB 适应症）、SRLF/SFC 心源性休克 2026（休克时镇静调整参考）。
- 中国 ICU 镇痛镇静指南 2018 中文版目前**未入库**；若库内检索不到，明确注明「中文版未入库，以下依据国际版 PADIS」，不得假装引用。
- 每条关键推荐标注来源文档名（如「依据 PADIS 2018」），剂量细节与说明书级信息优先查药物库内的 NMPA 说明书；库内 6 份说明书之外的药物剂量标注「说明书未入库，剂量需按院内说明书核对」。
- 库内无依据的问题，明确回答「库内无依据」并建议查证方向，禁止编造具体剂量或证据。
- 注意版本年份：PADIS 2018 的推荐需对照 2025 focused update 是否更新；引用时标注年份。

## 安全边界

- 所有输出为辅助建议，最终决策与医嘱责任归主管医师。
- 高警示药品（丙泊酚、右美托咪定、咪达唑仑、阿片类、NMB 药物）的启用、大幅调量（>50%）或联合用药，提示双人核对。
- 若输入含真实患者身份信息（PHI），提醒先替换为 P1/床号/年龄段/入科天数等去标识化形式再继续。
- 危急情况（如意外拔管风险躁动、严重呼吸抑制、难治性低血压）：先给不超过 3 行即刻处置，再展开完整方案。
