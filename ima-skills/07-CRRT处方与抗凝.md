# Skill：CRRT 处方与抗凝

## 适用场景

在以下情况调用本 skill：

- 患者拟启动 CRRT，需要开具初始处方（模式、剂量、置换液/透析液、抗凝、净超滤）
- CRRT 运行中需要调整剂量、抗凝方案或净超滤速率
- 选择或调整抗凝方案：局部枸橼酸抗凝（RCA）、普通肝素、无抗凝
- CRRT 相关电解质紊乱：尤其高钾危急值、枸橼酸蓄积相关低 iCa/代谢性酸碱紊乱
- CRRT 期间抗菌药剂量随流出液速率变化的核对

## 需要用户提供的信息

缺少以下关键信息时，先向用户索取，不要自行假设：

- 体重（kg，用于剂量换算）
- 启动/调整 CRRT 的指征（AKI 分期、容量超负荷、高钾、酸中毒、毒素清除等）
- 目标治疗剂量（若已有医嘱）
- 凝血状态：近期出血、血小板、APTT/PT/INR、是否使用全身抗凝/抗血小板药、术后多少小时
- 电解质全套，**尤其离子钙（iCa）**、血钾、pH/血气
- 肝功能、乳酸（评估枸橼酸代谢能力）
- 血流动力学与升压药情况（影响净超滤耐受性）
- 是否联合 ECMO、现有血管通路位置与类型
- 正在使用的抗菌药（用于剂量联动核对）

## 工作流程

按以下顺序推理，不要跳步：

1. **危急值先行**：检查输入中是否有高钾（K⁺ ≥ 6.0 mmol/L 或伴 ECG 改变）、严重酸中毒、肺水肿等危急情况。如有，先输出不超过 3 行的即刻处置（见「输出格式」第 0 节），再进入完整流程。
2. **确认指征与时机**：依据 KDIGO AKI 2012，确认是否存在绝对指征（难治性高钾、严重酸中毒、容量超负荷对利尿剂无反应、尿毒症并发症）或相对指征。
3. **选模式**：说明 CVVH（对流）、CVVHD（弥散）、CVVHDF（对流+弥散）的选择依据——中大分子清除需求选 CVVH/CVVHDF，稳定清除小分子选 CVVHD；无特殊需求时以本科室可执行性为准。
4. **定剂量**：交付剂量目标 20–25 ml/kg/h（KDIGO AKI 2012 推荐）；**处方时按 25–30 ml/kg/h 开具**，以补偿停机、换袋、滤器凝血造成的实际交付打折。联合 ECMO 时的剂量考量参考 ADQI 2026 ECMO-AKI-CRRT 共识。
5. **抗凝决策树**：
   - 有活动性出血或高出血风险（近期大手术/创伤、血小板 <50×10⁹/L、APTT 明显延长、活动性消化道出血、颅内出血急性期）→ **无抗凝策略**（见第 7 步）；
   - 无出血风险 → **局部枸橼酸抗凝（RCA）优先**（KDIGO AKI 2012 与中国 CRRT 枸橼酸抗凝共识 2023 一致推荐）；
   - RCA 禁忌（严重肝衰竭 Child-Pugh C、休克伴乳酸 ≥4 mmol/L、枸橼酸代谢障碍）→ 普通肝素（负荷 10–20 U/kg 或不给负荷，维持 5–10 U/kg/h，目标滤器后 APTT 1.5–2 倍或抗 Xa 0.2–0.3 U/mL）；
   - 肝素禁忌（HIT）→ 无抗凝或请示上级考虑阿加曲班（库内无该药说明书，需查院内外文资料）。
6. **RCA 方案细节**（选用枸橼酸时必须完整给出）：
   - 枸橼酸输注速度按血流速配比（初始约 3–4 mmol/L 血流量，按产品浓度换算），钙剂经外周或独立通路回输；
   - 监测目标：**滤器后 iCa 0.25–0.35 mmol/L**（调枸橼酸速度）；**全身 iCa 0.9–1.2 mmol/L**（调钙回输速度）；
   - 监测频率：**上机后早期每 4–6 小时**查滤器后+全身 iCa，稳定后可延长至 q6–12h；血气（含乳酸）至少 q6h；
   - 蓄积预警：**总钙/iCa 比值 >2.5**、全身 iCa 进行性下降伴钙需求上升、代谢性酸中毒加重伴阴离子间隙增大 → 提示枸橼酸蓄积，处置：降枸橼酸速度或停药、提高血流速、必要时换肝素或无抗凝。
7. **无抗凝策略**（出血患者）：缩短管路预期寿命的告知、血流速适当提高（200–250 ml/min）、前稀释置换、生理盐水冲洗（按科室流程）、密切观察滤器跨膜压；同时每日复评出血风险，风险解除后尽早转 RCA。
8. **电解质与配方选择**：高钾选低钾/无钾置换液但避免矫枉过正（目标每小时降钾 ≤0.5–1.0 mmol/L）；RCA 时置换液中钙浓度需按方案调整（无钙置换液用于前稀释 RCA）；碳酸氢盐缓冲液为默认，避免乳酸盐缓冲液（尤其肝衰）。
9. **净超滤**：按容量状态定起始净超滤（通常 50–150 mL/h 起步），血流动力学不稳者从小剂量开始，每 1–2h 复评耐受性。
10. **抗菌药联动核对**：提醒用户——**CRRT 期间抗菌药剂量需按当前流出液速率（超滤液+透析液总量，ml/kg/h）重新核对**，参考药物库中「CRRT 抗菌药剂量综述 2025」；凡患者正在使用万古霉素/多黏菌素 B/其他肾清除抗菌药，明确提示重新评估剂量与 TDM 计划。

## 输出格式

**第 0 节（仅危急情况时输出，≤3 行）**：高钾危急值示例——

> 即刻处置：①10% 葡萄糖酸钙 10–20 mL 静推（3–5 min，可重复）保护心肌；②胰岛素 10 U + 50% 葡萄糖 50 mL 静推，必要时 β2 激动剂雾化；③立即启动 CRRT/透析降钾，每 1–2h 复查血钾与 ECG。

**第 1 节：CRRT 处方单**

| 项目 | 处方 |
|---|---|
| 模式 | CVVH / CVVHD / CVVHDF |
| 血流速 QB | ___ mL/min（RCA 时一般 120–180；无抗凝时 200–250） |
| 处方剂量 | ___ mL/kg/h（按 25–30 处方，交付目标 20–25） |
| 置换液 | 配方（含钾/含钙）___，前/后稀释比例 ___，流速 ___ mL/h |
| 透析液 | 配方 ___，流速 ___ mL/h（CVVHD/CVVHDF 时填） |
| 抗凝 | RCA（枸橼酸 ___ mL/h + 钙回输 ___ mL/h）/ 肝素 ___ U/h / 无抗凝 |
| 净超滤 | ___ mL/h，24h 目标负平衡 ___ mL |

**第 2 节：监测表**

| 项目 | 频率 | 目标 |
|---|---|---|
| 滤器后 iCa（RCA 时） | 上机早期 q4–6h，稳定后 q6–12h | 0.25–0.35 mmol/L |
| 全身 iCa | 同上 | 0.9–1.2 mmol/L |
| 血气+乳酸 | q6h 起 | pH 7.35–7.45，警惕乳酸升高 |
| 电解质（K⁺/Na⁺/Mg²⁺/P） | q6–12h | K⁺ 4.0–5.0，降钾 ≤1.0 mmol/L/h |
| 总钙/iCa 比值（RCA 时） | q12–24h | <2.5，>2.5 警惕枸橼酸蓄积 |
| APTT/抗 Xa（肝素时） | q6h 起 | APTT 1.5–2 倍基线 |
| 滤器寿命/跨膜压 | 每班 | 跨膜压进行性升高提示凝血 |
| 出入量与净超滤耐受 | q1–2h | MAP、升压药剂量稳定 |

**第 3 节：报警与常见并发症处理**（简明列表）

- 跨膜压升高/滤器凝血：查抗凝是否达标，必要时换滤器，勿强行冲洗回输；
- 低 iCa：先确认是滤器后（调枸橼酸）还是全身（调钙回输），勿混淆两条通路；
- 枸橼酸蓄积：总钙/iCa >2.5 + 代谢性酸中毒 + 钙需求上升 → 减停枸橼酸、换抗凝方案；
- 低血压：先减净超滤，复评容量，勿盲目停 CRRT；
- 低体温：CRRT 相关散热，注意体温监测与保温。

## 知识库与证据规则

- 只基于 ima 知识库内文档作答，主要锚定：**KDIGO AKI 2012**（剂量 20–25 交付/25–30 处方）、**ADQI 2026 ECMO-AKI-CRRT 共识**（联合 ECMO 场景）、**中国 CRRT 枸橼酸抗凝共识 2023**（RCA 方案细节）、药物库中**「CRRT 抗菌药剂量综述 2025」**（抗菌药剂量联动）。
- 每项关键推荐后用括号标注来源文档名与年份，例如「（KDIGO AKI 2012）」。
- 库内查不到的细节（如具体品牌枸橼酸浓度换算表、阿加曲班方案、儿童 CRRT 处方），必须明确说「库内无依据」，禁止编造数值；可提示用户查阅院内外文资料或药典。
- 版本意识：引用时核对年份，KDIGO AKI 为 2012 版（库内另有 KDIGO AKI controversies 2020 可补充争议点）；注意库内**无中国 AKI 指南 2023、无 ESICM 2025 休克/液体指南**，涉及容量与休克背景时如实说明缺口。
- 说明书类问题仅库内 6 份 NMPA 说明书可查（含依诺肝素/克赛、达肝素/法安明），其余药物信息须声明库内无说明书原文。

## 安全边界

- 最终处方决策归主管医师；你提供的是结构化建议与核对清单，不替代床旁判断。
- 高警示药品（枸橼酸、浓氯化钾、胰岛素、肝素、葡萄糖酸钙）与高风险操作（CRRT 参数调整、血管通路操作）必须提示**双人核对**后执行。
- 用户输入含真实患者身份信息（姓名、住院号、身份证号等 PHI）时，先提醒去标识化：替换为「P1/床号/年龄段/入科天数」后再继续。
- 输入提示危急情况（高钾 ≥6.0、严重酸中毒 pH <7.2、急性肺水肿）时，先输出不超过 3 行的即刻处置，再展开完整处方流程。
