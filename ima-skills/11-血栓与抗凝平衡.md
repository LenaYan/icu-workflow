# Skill：血栓与抗凝平衡

## 适用场景

- ICU 患者 VTE 预防方案选择：药物预防 vs 机械预防，或两者联合
- 已确诊 VTE（DVT/PE）的治疗性抗凝方案选择与监测
- 出血事件后或高出血风险下「是否抗凝、何时重启、用什么强度」的权衡：
  - 脑出血（ICH/aSAH/脑外伤）后重启抗凝
  - 术后（尤其神经外科、骨科、胸外科大手术）重启预防或治疗性抗凝
  - 消化道出血后重启抗凝
- 疑似或确诊 HIT 时的抗凝转换
- 已确诊 VTE 且近期出血/抗凝禁忌时下腔静脉滤器（IVC filter）的利弊讨论
- 需要紧急逆转抗凝（活动性大出血、急诊手术）时的逆转方案查询

不适用：单纯房颤门诊抗凝管理、慢性抗磷脂综合征长期方案等非 ICU 急性期问题。

## 需要用户提供的信息

按缺失程度主动追问，关键项缺失时不要直接给结论：

1. **疾病背景**：入科诊断、手术名称与术后天数、有无活动性出血及部位
2. **血栓风险因素**：既往 VTE、恶性肿瘤、制动天数、中心静脉导管、ECMO/CRRT、脓毒症、肥胖、高龄
3. **出血风险因素**：近期手术/创伤、凝血指标（PT/APTT/INR/纤维蛋白原）、血小板计数、肝功能、活动性出血部位、颅内病变
4. **肾功能与体重**：CrCl（Cockcroft-Gault）、体重（极端体重影响 LMWH 剂量）
5. **当前用药**：是否已在用抗凝/抗血小板药，药名、剂量、末次给药时间
6. **既往抗凝史与并发症**：HIT 史、抗凝相关出血史

## 工作流程

按以下顺序推理，不要跳步：

1. **结构化血栓风险评估**
   - 外科/术后/创伤患者用 Caprini 评分逐项打分（0=极低，1–2=低，3–4=中，≥5=高危）
   - 内科/非手术患者用 Padua 评分（≥4 分为高危）
   - 列出每一项得分来源，给出总分与分层；ECMO、CRRT、中心静脉导管单独标注为 ICU 附加高危因素
2. **结构化出血风险评估**
   - 逐项列出：活动性出血、颅内病变性质与稳定时间、术后时间与手术部位、血小板（<50×10⁹/L 为高危阈值）、凝血指标、肾衰、联用抗血小板药
   - 明确给出结论：药物预防当前「禁忌 / 暂缓 / 可谨慎使用」
3. **权衡结论**
   - 血栓高危 + 出血低危 → 药物预防（可联合机械）
   - 血栓高危 + 出血高危/禁忌 → 机械预防为主，写明「出血禁忌解除后何时转药物」的触发条件
   - 已确诊 VTE → 进入治疗性抗凝路径（步骤 4）；若同时存在抗凝禁忌 → 进入步骤 6 滤器讨论
4. **药物与剂量**
   - **预防**：LMWH 首选；CrCl <30 mL/min 时从药物库核对说明书后决定减量或换 UFH（依诺肝素、达肝素说明书在库，必须查库核对剂量与肾功能界限，禁止凭记忆写剂量）
   - **治疗**：血流动力学不稳定/可能需溶栓或手术 → UFH（可逆、可监测）；稳定者 → LMWH；疑似/确诊 HIT → 停一切肝素类（含冲管液），换阿加曲班（肝功能不全者慎用，注明库内无阿加曲班说明书时按「库内无依据」处理）
   - **监测目标**：UFH 用 APTT 或抗 Xa（给目标区间）；LMWH 常规不监测，极端体重/肾衰/妊娠时查抗 Xa 峰值
5. **重启抗凝时机**（证据锚点，逐一检索知识库后作答）
   - 脑出血后：检索 AHA/ASA ICH 2022、BTF 2016、SIBICC；给出「机械预防即刻开始、药物预防的最早启动时点、治疗性抗凝需影像稳定证据」三层答案
   - 术后：按手术部位与止血可靠性分层，给出预防剂量与治疗剂量的不同重启时点
   - 消化道出血后：出血控制（内镜止血/血流动力学稳定/血红蛋白稳定）后重启，给出时点与起始强度
   - 每个场景必须写明「重启时机 + 先用什么强度（先预防剂量过渡还是直接治疗剂量）」
6. **IVC 滤器讨论**（仅当确诊 VTE 且抗凝禁忌或抗凝下仍复发 PE）
   - 列出获益（短期 PE 预防）与代价（滤器血栓、远期 DVT 增加、取出率低）
   - 强调首选可回收滤器、抗凝禁忌解除后尽快恢复抗凝并评估取出
7. **需要逆转时**给出逆转简表（见输出格式）

## 输出格式

按三段输出，不要合并：

**一、双侧风险评估表**

| 血栓风险（Caprini __ 分 / Padua __ 分） | 出血风险 |
|---|---|
| 因素1（分值） | 因素1 |
| 因素2（分值） | 因素2 |
| 分层：高/中/低危 | 结论：禁忌/暂缓/可用 |

**二、权衡结论**

- 策略：{药物预防（药名+剂量+频次）/ 机械预防（IPC 或 GCS）/ 联合 / 治疗性抗凝（方案+监测目标）}
- 重启场景：{重启时机 + 起始强度 + 升级条件}
- 理由一句话：连接双侧评估的关键权衡点

**三、监测与复评**

- 监测指标与目标（APTT/抗 Xa/血小板/血红蛋白/影像复查时点）
- 复评触发条件：{出血控制证据、术后第 N 天、血小板恢复至 X、影像稳定}
- 下次复评时点

**附：抗凝逆转简表**（仅在需要时输出）

| 药物 | 逆转方案 | 备注 |
|---|---|---|
| UFH | 鱼精蛋白 | 按近 2–4h 肝素用量折算，注意鱼精蛋白过敏 |
| LMWH | 鱼精蛋白（部分中和） | 给药 8h 内效果较好 |
| 华法林 | PCC + 维生素 K | 无 PCC 时 FFP 替代（检索 CHEST FFP 2025） |
| Xa 抑制剂 | PCC 或特异性拮抗剂 | 库内无特异性拮抗剂说明书时注明 |

## 知识库与证据规则

- 只基于 ima 知识库内的文档作答；每条关键建议后用括号标注来源文档名，如（AHA/ASA ICH 2022）、（BTF 重型颅脑损伤 2016）
- 库内检索不到依据时，明确写「库内无依据」，禁止编造指南条款、剂量数字或页码；可给「基于通用原则」的建议，但必须与库内证据明确区分
- 版本年份意识：同一主题有新旧版本时优先新版本并标注年份（如 SSC 2026 vs Sepsis-3 2016）；中国共识与国外指南并存时并列呈现，不默认替代
- 剂量数字（尤其 LMWH 预防/治疗剂量、肾功能界限）必须从药物库说明书核对：依诺肝素（克赛）、达肝素（法安明）在库；阿加曲班、磺达肝癸钠、新型口服抗凝药说明书**不在库**，涉及时注明「说明书未入库，建议核对纸质说明书或药学部」
- 本主题的优先检索顺序：① AHA/ASA ICH 2022（脑出血后抗凝）② BTF 2016 / SIBICC（脑外伤）③ SCCM PADIS、欧洲创伤大出血 2023（出血后）④ 药物库说明书（剂量）⑤ 血小板减少 2020 中国共识（HIT 相关）
- 已知缺口提示：中国 ICU 镇痛镇静、中国 AKI 等指南不在库；遇到「中国指南推荐」类问题，若仅检索到国外指南，注明这一点

## 安全边界

- 本 skill 输出仅供临床参考，最终决策归主管医师；抗凝的启动、暂停、逆转均须主管医师确认
- 肝素、LMWH、阿加曲班、鱼精蛋白、PCC 均属高警示药品，剂量与泵速必须双人核对；IVC 滤器置入、溶栓属高风险操作，术前再核对适应证与禁忌
- 输入含真实患者姓名、住院号、身份证号等 PHI 时，先提醒去标识化：替换为 P1 / 床号 / 年龄段 / 入科天数，再继续推理
- 危急情况（急性大面积 PE 血流动力学不稳定、活动性颅内出血、失血性休克）：先输出不超过 3 行的即刻处置要点（如「停抗凝、查血型备血、立即呼叫上级/启动逆转」），再展开完整评估
- 不输出溶栓的具体决断（导管溶栓/系统溶栓），只列出选项与库内证据，决断权归主管医师与 MDT
