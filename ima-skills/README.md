# ima copilot Skill 库

腾讯 ima copilot 的自定义 Skill 指令，配合 ima 知识库使用。

**导入方式**：ima 的「添加 Skill」支持 ZIP / MD（≤10MB），MD 必须带 YAML
frontmatter（`name` + `description`）。本目录文件已带 frontmatter，在 ima
里逐个上传 `.md` 文件即可（不是复制粘贴正文）。`name` 用了小写英文 slug
（兼容性格式），显示名以 ima 解析为准。

知识库素材来源：`guidelines/_pdfs/`（见 `INDEX.md` 与 `BACKLOG.md`）。
ima 知识库分库方案：指南共识库、药物库、文献库、科室 SOP 库（院内规定先确认）、教学库。

## 共同设计原则

所有 skill 内置相同的约束：

- **库内优先**：只基于知识库作答，检索不到就说「库内无依据」，禁止用模型
  记忆编造数值或引用。
- **版本意识**：引用带年份；新旧版本冲突时以新版为准并提示（如 SSC 2026
  取代 2021）。
- **已知缺口**：ESICM 2025 休克指南与液体治疗三部曲、中华系列部分指南、
  大部分 NMPA 说明书尚未入库（见 `guidelines/_pdfs/BACKLOG.md`），skill 已
  写明遇到缺口时的兜底行为。
- **安全边界**：最终决策归主管医师；高警示药品双人核对；PHI 去标识化提醒；
  危急情况先给 ≤3 行即刻处置。

## 使用注意

- **真实病例资料不进 ima**（云端服务）。先用 Skill 13 脱敏，再贴给其他 skill。
- ima 的 RAG 可能检索不全或引用错位，剂量、适应证等关键结论回原文核对。
- 第三方 Skill 广场和 MCP 不要接入含科室资料的知识库。
- 新增指南入库（BACKLOG 补齐）后，回这里更新对应 skill 的「已知缺口」表述。
