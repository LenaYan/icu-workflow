## 7. 血液 / 凝血 — **本例核心**

### 需解决的问题

评估 PLT 34、Fib 0.81、D-dimer 25.12 + 全身瘀斑 + 反复多部位出血的根本病因；权衡致命性 SAH（绝对抗凝禁忌）vs 双下肢 DVT + IVC 滤网在位（血栓必管）；制定止血方案 + 抗凝重启路径。

### 7.1 病因 / 鉴别诊断（问题 1）

**最可能诊断**：**Trousseau syndrome — 肺癌相关 DIC，高纤溶型**（hyperfibrinolytic form）[1][2]。

**诊断依据**：

- **基础疾病**：播散性恶性肿瘤是 DIC 最常见触发因素，DIC 被视为癌症相关副肿瘤综合征 [1][3]。肺癌（尤其腺癌 / 黏液型）+ 反复多部位 VTE + 消耗性凝血病 + 低纤维蛋白原 = 经典 Trousseau 三联 [2]。
- **实验室高度吻合**：PLT 34 ×10⁹/L（< 50 → 2 分）、Fib 0.81 g/L（≤ 1.0 → 1 分）、D-dimer 25.12 mg/L（显著↑ ≥ 5× ULN → 3 分）。**ISTH overt DIC 评分 = 6 分**，≥ 5 分阈值明确诊断 [4]。
- **亚型特征**：Fib 极度↓ 而 D-dimer 极度↑ 符合癌相关 DIC 的高纤溶型病理生理 — 与产科 / 创伤的高凝型截然不同；ISTH 2015 指出该亚型 Fib 可急剧下降是其最常见止血异常 [2]。
- **血小板功能附加证据**：AA 通路聚集↓（39.4%）、GP IIb/IIIa 受体↓（32.3%）、ATP 释放严重↓（18.18%）→ 致密颗粒受损，提示功能性血小板缺陷叠加（消耗 + 肿瘤微环境）。

**鉴别诊断**：

1. **TMA / 肿瘤相关 MAHA** — 待外周血涂片找 schistocytes，LDH、间接 Bil、网织、Coombs、结合珠蛋白；ADAMTS13 必要时
2. **HIT** — 既往皮下抗凝 2 个月（药物名待补），现 PLT 34 + 血栓背景符合警示；必查 **4Ts 评分**，> 4 分加抗 PF4 抗体 [5]
3. **靶向药 / 化疗骨髓抑制** — 配合骨髓象、用药史；EGFR-TKI、ALK-i、奥希替尼均可致 PLT↓ [14]
4. **利伐沙班残效** — 半衰期 5–13h，肾功不全延长；不解释 PLT/Fib 消耗，仅是出血加重因素 [6][7]

**与当前治疗关系分析**：

利伐沙班是直接 Xa 抑制剂，作用于凝血酶生成下游，**本身不导致 PLT↓ 或 Fib↓ 消耗** [6][7]。虽然其禁用于 PLT < 50 [7][8]，但本例 PLT/Fib 异常的根本原因是 DIC 背景下的消耗性凝血病 [1]，**非利伐沙班药理作用**；其残效是当前 SAH 与全身瘀斑的**加重因素**而非根因。

### 7.2 出血风险评估（问题 2）

**当前风险等级**：**极高，致命性出血高危状态**。

支持依据：
- 活动性危及生命颅内出血（影像确诊 SAH）
- 重度血小板减少 PLT 34 + 重度低纤维蛋白原 Fib 0.81（< 1.0 g/L 即显著出血风险）[9][11]
- 利伐沙班停 48h 抗凝活性可能未完全消退（半衰期 5–13h，肾功不全延长）[6][7]
- HTN + 肿瘤高凝背景叠加

### 7.4 急性期止血策略（问题 3.1 — 抗凝绝对禁忌）

**核心原则**：活动性 SAH + 重度 PLT↓ / Fib↓ → **抗凝绝对禁忌**（CSCO 2019）[8]，全力止血。

**立即执行医嘱**：

- **单采血小板 1 治疗量 ivgtt st!**，输后查 PLT；目标：无 ICH → PLT ≥ 50；本例 SAH 在位 → **PLT ≥ 100** [9][10]
- **人纤维蛋白原 4 g ivgtt st!**（或冷沉淀 10 U；50 kg 起算）；目标：本例 ICH 场景 **Fib ≥ 2.0**；其他大出血 ≥ 1.5 [11]
- FFP 仅在 PT/APTT > 1.5× ULN 考虑（10–15 mL/kg）
- RBC 触发：一般 Hb < 70；缺血 / SAH 痉挛期 < 80–90（TRICC）[12]
- ❌ **禁用全身 TXA**（除鼻腔局部填塞）— Trousseau 高凝 + VTE × 2 + IVC 滤网 → 微血栓 / 滤网血栓风险；ISTH 2015 在癌相关 DIC 中亦限制使用 [2]

**致命性出血时逆转利伐沙班残效**：

- andexanet alfa（国内未普及）
- **4F-PCC**（首选可及方案）：本例 VTE × 2 + IVC 滤网 + 肿瘤高凝 → 血栓风险高
  - **起始 25 IU/kg ivgtt**（50 kg → 1250 IU）
  - 按出血改善 / Fib / 神经体征追加至 50 IU/kg（50 kg → 2500 IU）
  - 依据：低剂量分组安全性更优（Blood 2017 队列）[13]
- 维生素 K1 10 mg iv（证据弱，可经验性）

**升 PLT 药物**（仅在鉴别后存在靶向药骨髓抑制叠加时启用，单纯 DIC 消耗不首选）：

- rhTPO 15,000 IU sc QD × 7–14d [14]
- rhIL-11 25–50 μg/kg sc QD × 7–14d（注意水钠潴留、过敏）[14]

### 7.5 抗凝过渡决策（问题 3.2）

**触发判断 — 基于复查头颅 CT 与神经查体**：

```
                  头颅 CT（≤ 24h 内必做）+ 神经查体
                              │
                ┌─────────────┴─────────────┐
                │                            │
        证实/进展性 ICH / SAH         无新发 / 稳定颅内出血
                │                            │
        ━━━━━━━━━━━━━━━              ━━━━━━━━━━━━━━━━━━━━━━━
        路径 A：暂停所有抗凝          路径 B：按 PLT 分层桥接 [15]
        ━━━━━━━━━━━━━━━              ━━━━━━━━━━━━━━━━━━━━━━━
        • IVC 滤网作为机械保护         触发：Fib ≥ 1.5 + 24h 无活动出血
        • PLT/Fib 持续支持             • PLT ≥ 50  → LMWH 全剂量
        • 7-14d 后复查影像             • PLT 25-50 → LMWH 半剂量 + 严密监测
                                       • PLT < 25  → 暂不抗凝，机械预防 +
                                                     输 PLT 后再评估
                                       • 一律不回 DOAC（NCCN 2025）[15]
                                       • 首选 LMWH（CLOT [16] / CARAVAGGIO [17]）
```

**LMWH 方案（路径 B 启用时）**

**首选 — 达肝素（Dalteparin，CLOT 原方案）** [16]
- 首月：200 IU/kg sc QD → 50 kg = 10,000 IU sc QD
- 2–6 月：150 IU/kg sc QD → 50 kg = 7,500 IU sc QD
- 肾调整：CrCl 20–30 → 减量 ~25%；CrCl < 20 → 改 UFH
- 监测：抗-Xa 峰值（注射后 4h）0.5–1.0 IU/mL

**次选 — 依诺肝素**
- 1 mg/kg sc q12h（治疗量；50 kg → 50 mg sc q12h）
- CrCl 15–30 → 1 mg/kg sc QD；CrCl < 15 → UFH

**国内常用 — 那屈肝素**
- 86 IU/kg sc q12h（50 kg → 4,300 IU sc q12h；按规格取 0.4 mL）
- CrCl < 30 → 减量 25–33% 或 UFH

**肾衰 / 高出血风险 / 需快速可逆 — UFH 泵入**
- 不予 bolus；维持 18 IU/kg/h iv pump
- 监测 APTT q6h 目标 1.5–2.5× baseline 或 50–80s
- 中和：鱼精蛋白 1 mg / 100 IU UFH（过去 2h 累计量）

**DOAC 在 CAT 中的地位 & 本例排除**：CARAVAGGIO 中阿哌沙班 non-inferior 但不含脑癌 [17]；Hokusai-VTE Cancer 依度沙班 GI 出血升高 [19]；SELECT-D 利伐沙班 CRNMB↑ [20]。NCCN 2025 V3 在 PLT < 50 明确**不用 DOAC** [15]；本例脑转移 + Trousseau + PLT 34 → 三重排除 DOAC。

### 7.6 HIT 处理（若 4Ts ≥ 4）

立即停所有肝素类。

- **阿加曲班（Argatroban）持续泵入**：起始 2 μg/kg/min iv（无负荷）；肝功不全（Child B/C、TBil↑）→ 0.5 μg/kg/min 起；监测 APTT 1.5–3.0× baseline；会延长 INR，影响后续华法林 [5]
- 替代：**磺达肝癸钠** 7.5 mg sc QD（出血状态慎用）[5]

### 7.7 VTE 机械预防（抗凝暂停期间）

- [ ] 双下肢 IPC ≥ 18h/d
- [ ] 弹力袜（无下肢溃疡时）

## 关键证据 / 试验快引

| 试验 / 指南 | 要点 |
|---|---|
| **CLOT (Lee NEJM 2003)** | LMWH (达肝素) > VKA 用于 CAT 长期抗凝 |
| **CATCH (JAMA 2015)** | 替奈普素同样优于 VKA |
| **Hokusai-VTE Cancer (NEJM 2018)** | 依度沙班 non-inferior，但 GI 出血更高（GI/GU 肿瘤慎用） |
| **SELECT-D (JCO 2018)** | 利伐沙班 VTE 复发↓但 CRNMB↑ |
| **CARAVAGGIO (NEJM 2020)** | 阿哌沙班 non-inferior 且大出血未增加（不含脑癌/急性白血病） |
| **ITAC 2022 / ASH 2021 / ASCO 2023** | 高出血风险（脑转移、近期 GI / GU 出血、严重血小板减少）→ **LMWH 优先** |
| **ISTH DIC 2013 / EHA-ISTH 2024** | overt DIC 评分；治疗以原发病为本，按表型支持 |
| **AABB 2015 / BSH 2017** | PLT 输注阈值：一般 < 10；操作 < 50；ICH < 100 |
| **BCSH 2022** | Fib 目标：大出血 ≥ 1.5；产科/ICH ≥ 2.0 |
| **PREPIC2 (JAMA 2015)** | IVC 滤网 + 抗凝相比单纯抗凝**无获益**，可回收滤网应及早取出 |
| **NICE-SUGAR (NEJM 2009)** | ICU 血糖 7.8-10 mmol/L |

6. **体重 / 身高 / BSA** + Cr / eGFR — 精算剂量
7. **化疗史 / 激素史** — PJP 风险评估
