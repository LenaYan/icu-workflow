# cases/ — 病例、查房、交班、疑难病例讨论

## 一、PHI 去标识化规范（必读）

**所有进入本目录的文件都视为可能被 git 提交。在写入前先去标识化。**

### 不可写入（HIPAA Safe Harbor 18 项 + 中国大陆等价）
| # | 类别 | 说明 |
|---|---|---|
| 1 | 姓名 | 真实姓名、英文名、昵称 |
| 2 | 身份证号 | 全部 18 位 |
| 3 | 手机号 | 全部 11 位 |
| 4 | 住址 | 街道、门牌、邮编精确到 5 位 |
| 5 | 电子邮件 | 完整 email |
| 6 | 病案号 | 完整 ID — **仅保留末 4 位** |
| 7 | 出生日期 | 精确日期 — 改为年龄段（如 65–70 岁） |
| 8 | 住院/手术日期 | 精确日期 — 模糊到年-月（如 2026-05） |
| 9 | 工作单位 / 学校 | |
| 10 | 设备序列号 | ECMO/呼吸机序列号、CT 影像 UID |
| 11 | IP / 账户 | |
| 12 | 生物识别 | 指纹、人脸、声纹 |
| 13 | 全脸照片 / 可识别影像 | 去除 DICOM header 中 PatientName/ID |
| 14 | 任何其他唯一标识 | 包括罕见病组合可被反查的特征 |
| 15–18 | 详见 HIPAA §164.514 | |

### 可以写入（推荐格式）
- 床号：`ICU-12床`
- 简称：`P1`、`P2`（按本次讨论顺序）或 `M-65y`（性别-年龄段）
- 病案号末 4 位：`MR ****1234`
- 日期：`2026-05`（住院月份）/`D1, D3, D7`（入科后第几天）
- 入院诊断与治疗经过完整保留

### 示例
✅ `P1, M, 60-65y, ICU-08, MR ****5821, D3：sepsis + ARDS P/F 120, NE 0.4 μg/kg/min, VV-ECMO d2…`
❌ `张某某, 男, 62岁, 身份证 3201...0815, 2026-05-12 入 ICU…`

### 一键检查
准备提交前，让 Claude 跑一遍 PHI 扫描：
> "扫描 cases/ 目录里有没有 PHI 残留"

## 二、目录组织

```
cases/
├── README.md                # 本文件
├── _templates/              # 模板（不放真实病例）
│   ├── SOAP.md
│   ├── 系统化-by-system.md
│   ├── handover-3段.md
│   ├── MDT-discussion.md
│   ├── mortality-review.md
│   └── transfer-out.md
└── YYYY-MM/                 # 病例按月归档
    └── P{n}-{简短主诊断}.md  # 例：P1-septic-shock-ARDS.md
```

## 三、常用动作

| 想做的事 | 模板 | 怎么问 Claude |
|---|---|---|
| 入科首程 | `SOAP.md` 或 `系统化-by-system.md` | "按系统化结构梳理这个 case：…" |
| 早交班 | `handover-3段.md` | "整理这个患者的交班：问题列表 + active issues + 24h plan" |
| 疑难讨论 | `MDT-discussion.md` | "把这个 case 整理成 MDT 讨论稿，按 PICO 提出问题" |
| 死亡讨论 | `mortality-review.md` | "按可避免性分级整理这例死亡讨论" |
| 转科/转院 | `transfer-out.md` | "写一份转出 ICU 的交接小结" |

## 四、协作约定

- 病例文件 frontmatter 建议加 `deidentified: true` 标志，便于检索
- 涉及罕见病/小样本时尤其谨慎（特征组合即可身份化）
- 病例讨论结论里的临床决策**最终归用户**；Claude 只对照证据与指南
